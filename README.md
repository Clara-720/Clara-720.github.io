# Mingjing Hou — Portfolio

Personal portfolio for Mingjing Hou, a Linguistic Data Science master's student in Bochum working across NLP, data analysis, visualisation and digital marketing.

[View the live portfolio →](https://clara-720.github.io/)

The site is bilingual (German / English) and brings together a research project on narrative representation and audience reception, professional experience at TTI Asia and Unilever, selected methods, education and contact details.

## Highlights

- Cinematic Emotion Map research project using Python, pandas, DistilRoBERTa, KeyBERT and statistical analysis
- Digital marketing experience across LinkedIn, YouTube, WeChat and Bilibili in the Asia-Pacific region
- Responsive editorial layout with German and English language switching
- Accessible links to the interactive research map, LinkedIn and email

## Local development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
